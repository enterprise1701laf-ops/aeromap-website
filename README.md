# PROJECT AEROMAP — Research Showcase

Responsive static website with a NERV-inspired research operations interface.

## Run locally
Open `index.html` in a modern browser. No build tools are required.

## Publish
Upload the contents of this folder to a GitHub repository and enable GitHub Pages from `main` / root.

## Evidence and content notes
- Project description, objectives, conclusion, recommendations and reported test figures are based on the supplied one-page AEROMAP research poster.
- The poster states 99% of the population breathes air exceeding the WHO limit and 7.9 million premature deaths. These are labelled as poster-cited global context, not AEROMAP measurements.
- The poster reports 100% of missions completed, approximately 7% flight-path deviation, 2 km/h during testing and a 1,083 m² testing area.
- 10 km range, 7 km altitude and 90 km/h maximum speed are explicitly labelled theoretical, not field-validated performance.
- No experimental data or operational capabilities have been invented.
- Creator contact links use the supplied Facebook profile and phone number. An email address was not supplied, so the website marks it as pending.

Responsive CSS breakpoints and the collapsible navigation are included. The abstract and long-form content reflow to a single column on narrow screens; images scale to the available width.
